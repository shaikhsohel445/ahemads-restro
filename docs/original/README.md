# Original (self-hosted) documentation

These documents describe Nodedr OrderRestro (upstream,
<https://github.com/Raktim94/nodedr-restaurant-pos>), the self-hosted build this repository was migrated
from (Docker / CasaOS / Windows, PostgreSQL, Socket.IO). They are kept for
history and for the product background they contain. For how this edition
works, see [../cloudflare/](../cloudflare/README.md); where the two disagree,
the Cloudflare documents are correct for this repository.

Upstream-branded files kept here for history (they describe the original
product, not this edition): `orderrestro-cover.jpg`, `orderrestro-manual.html`,
`orderrestro-user-manual.pdf`, `assets/hero-animated.svg`,
`assets/install-animated.svg`. Relative links inside `README.self-hosted.md`
that pointed at the original repository's layout (screenshots, `casaos/`,
`install.sh`, `windows/`) no longer resolve in this repository.
